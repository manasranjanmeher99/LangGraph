# 🚀 LangGraph Tutorials and Examples

A beginner-friendly collection of LangGraph notebooks covering the fundamentals of graph-based AI workflows using LangChain and LangGraph.

This repository demonstrates how to build stateful AI applications, create graph workflows, and integrate Large Language Models into intelligent pipelines.

---

## 📚 Contents

- LangGraph Basics
- StateGraph Introduction
- Graph Nodes
- Conditional Edges
- Workflow Execution
- LangChain Integration
- Quickstart Examples

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/manasranjanmeher/LangGraph.git
```

Create virtual environment

```bash
python -m venv venv
```

Activate it

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Launch Jupyter

```bash
jupyter notebook
```
